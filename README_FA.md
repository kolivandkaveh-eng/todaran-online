# توداران آنلاین — نسخهٔ اولیه

این بسته، سرور چندنفرهٔ اولیه و نسخهٔ HTML بازی را در بر دارد. امکانات فعلی: ورود مهمان، اتاق عمومی واحد، نمایش بازیکنان دیگر به شکل آواتار، همگام‌سازی تقریبی موقعیت، گفت‌وگوی عمومی با محدودیت نرخ پیام و فیلتر ابتدایی، و مسیر سلامت سرور.

## اجرای آزمایشی روی کامپیوتر
1. Node.js نسخهٔ 20 یا جدیدتر نصب باشد.
2. در همین پوشه اجرا کنید: `npm install`
3. سپس: `npm start`
4. مرورگر را روی `http://localhost:3000` باز کنید.

## انتشار اینترنتی
- این پروژه برای میزبان Node.js دارای پشتیبانی WebSocket آماده شده است. فایل `render.yaml` تنظیم اولیهٔ استقرار را دارد؛ می‌توان آن را به یک سرویس وب Node متصل کرد.
- بعد از استقرار، آدرس HTTPS سرویس را باز کنید. فایل `public/index.html` و Socket.IO از همان دامنه ارائه می‌شوند.
- طرح رایگان، ظرفیت/پایداری/بیدارماندن تضمین‌شده ندارد و ممکن است محدودیت یا خواب سرویس داشته باشد. شرایط و قیمت میزبان را پیش از انتشار بررسی کنید؛ برای هر پرداخت یا تأیید حساب از سرپرست کمک بگیرید.

## محدودیت‌های این نسخه
- این نسخه هنوز روی اینترنت عمومی مستقر نشده و URL آنلاین ندارد.
- بازیکنان و موقعیت‌ها فقط در حافظهٔ سرور هستند؛ با راه‌اندازی مجدد سرور پاک می‌شوند. حساب کاربری، ذخیرهٔ ابری، دیتابیس، چند شهر/اتاق، ماشین‌های قابل مشاهدهٔ بازیکنان دیگر و ضدتقلب کامل هنوز پیاده‌سازی نشده‌اند.
- حرکت سمت سرور محدودسازی پایه دارد، اما ضدتقلب حرفه‌ای نیست. فیلتر چت ساده و ابتدایی است؛ برای انتشار عمومی واقعی باید گزارش/مسدودسازی سمت سرور، ابزار مدیریت، فیلتر قوی‌تر و سیاست حریم خصوصی اضافه شود.
- بازی اصلی همچنان به کتابخانهٔ Three.js از CDN نیاز دارد؛ برای اجرای بازی اینترنت لازم است.
- تعداد ۵۰ نفر فقط سقف تنظیمی اولیه است، نه ظرفیت تضمین‌شده؛ باید با تست بار سنجیده شود.

## ساختار
- `public/index.html` نسخهٔ بازی با رابط آنلاین
- `Todaran_Online.html` همان فایل مستقل برای نگهداری/دانلود
- `server.js` سرور Express + Socket.IO
- `package.json` وابستگی‌ها و فرمان اجرا
- `render.yaml` تنظیم نمونهٔ استقرار
